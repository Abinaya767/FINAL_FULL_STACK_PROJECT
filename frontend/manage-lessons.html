Lesson Management Rules

  • Every lesson must belong to an existing course and module.
  • Lessons must follow the correct learning sequence.
  • Each lesson should contain relevant subject content.
  • Learning objectives must be clearly defined.
  • Only published lessons should be visible to eligible students.
  • Student lesson completion must be tracked.
  • Lesson progress must be saved in MongoDB.
