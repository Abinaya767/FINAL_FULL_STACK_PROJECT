Module Management Rules

  • Each module must belong to an existing course.
  • Every course should contain at least 10 relevant modules.
  • Modules must follow the correct learning sequence.
  • Each module must contain its own lessons.
  • Each module must have a quiz with exactly 5 questions.
  • Students can unlock the next module only after completing the current module and passing its quiz.
  • Module completion progress must be saved in MongoDB.
  • Published modules are visible to enrolled students.
