Quiz Management Rules

  • Each module must have exactly five quiz questions.
  • Each question must contain four answer options.
  • Every question must have one correct answer.
  • Quiz questions must match the selected module's subject.
  • Students are allowed a maximum of two attempts.
  • Attempt limits must be enforced by the server.
  • Correct answers must never be exposed to student pages or browser responses.
  • Quiz results and attempts must be stored in MongoDB.
  • The next module unlocks only after the current module is completed successfully.
