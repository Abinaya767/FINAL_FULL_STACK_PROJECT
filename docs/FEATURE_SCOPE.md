# LearnSpace — Planned Feature Scope

## Student experience
- Public pages: Home, About, Courses, Course Details, Contact.
- Account: Student registration, login, profile, logout.
- Catalogue: Published courses, search, category/level/duration filters.
- Learning: Enrollments, saved courses, modules, lessons, completion tracking.
- Assessments: Five-question module quizzes, final assessment, server-enforced maximum of two attempts per assessment.
- Progress: Dashboard, resume learning, completed courses, learning history.
- Communication: Notifications and authorized support chat.
- Certificates: Eligibility-based certificate record and PDF delivery, using a design reference to be supplied later.

## Admin experience
- Private admin login; no public admin registration.
- Dashboard metrics derived from actual stored records.
- Course and content management, including draft/published status.
- Student search and authorized student-progress review.
- Quiz and final-assessment configuration.

## Explicit exclusions / constraints
- No course thumbnails.
- No fabricated reviews, testimonials, popularity rankings, counts, or success rates.
- No admin preview feature.
- No invented certificate design.
- Do not trust frontend state for authorization, progress, grading, or attempt limits.
- Avoid green in the eventual visual design; palette selection is deferred to the UI task.
